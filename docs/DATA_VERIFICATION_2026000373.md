## 3. 공급 구분 (정정본 51쪽)

| 구분 | 세대 |
|---|---|
| 총 건설호수 | **1,305** (전용 49㎡ 590 · 59㎡ 715) |
| 사전청약 당첨자 배정 | 592 |
| 신규 특별공급 | 566 (청년 106 · 신혼부부 106 · 생애최초 106 · 신생아 248) |
| 신규 일반공급 | 147 |
| 신규 특별 + 일반 | **713** |

- 청약홈 '공급세대수 계'와 공고 상세 API 의 세대수 합(713)은 **이번 청약 세대**다. 단지 규모가 아니다.
- 이전 화면의 '공급 713세대'는 단지 규모로 읽힐 수 있어 고쳤다. 지금은 '단지 1,305세대 · 이번 청약 713세대(특별 566 · 일반 147) · 사전청약 당첨자 592세대'로 나눠 적는다.
- 검산: 20개 타입의 총계·사전·본청약·일반 합이 1,305·592·713·147이고, 면적 줄 합이 590·715이다. 타입마다 총계 = 사전 + 본청약, 본청약 = 청년 + 신혼 + 생애최초 + 신생아 + 일반이다. 모두 테스트로 고정했다.

## 4. 면적 — 청약홈 표기와 공고문 값의 차이

청약홈과 API 의 주택형 표기 `059.0000B` 에서 읽은 전용면적은 59㎡다. 그러나 공고문의 주거전용은 **59.97㎡**다. 20개 타입 모두 이렇게 다르다(49.19~59.99㎡). 화면은 확인된 공고에서 공고문 값을 쓴다(`officialModel`).

- 세부타입(49C1·C2·C3, 59C1·C2, 59D1·D2, 59H1·H2)은 주거전용이 서로 다르다.
- 청약홈 공급면적은 첫 세부타입의 주거전용 + 주거공용과 같다. 예: 049.0000C 72.19 = 49.97 + 22.22.
- 청약은 대표타입으로만 하고, 세부타입은 무작위로 배정된다(52쪽).

## 5. 가격 — 건물 분양가와 토지임대료

- **건물 분양가**: 52~80쪽 동·호별 가격표 1,305행(천원 단위, 계약금 10% + 잔금 90%)이다.
  - 행 수는 타입별 총계(사전청약 포함)와 같다.
  - 타입별 최고가를 만원으로 내림한 값은 청약홈 '공급금액(최고가 기준)' 20줄과 같다. 예: 49H 295,676천원 → 29,567만원.
  - 화면은 타입별 최저~최고를 가격표에서 직접 계산한다.
- **발코니 확장비**: 81쪽. 세부타입별로 공급금액과 따로 낸다(49H 506,000원 ~ 59E 6,826,600원).
- **월 토지임대료**: 81쪽「5. 토지임대료」.
  - 전용 49㎡는 **426,000원**, 59㎡는 **511,500원**이다.
  - 공고 비고에 "전용 49㎡(59㎡) 전체 주택형에 동일 적용"이라고 적혀 있어, 같은 면적 줄의 모든 타입에 같은 값을 붙인다. 추정이 아니다.
  - 그 밖의 면적이나 다른 공고에는 값을 만들지 않는다(`landRentFor` → null).
  - 최대 60%까지 보증금으로 전환할 수 있다. 82쪽 예시는 전환이율 2.5%이며, 실제 전환이율은 계약 전에 안내된다.
- 화면 표기: 토지임대부 공고의 '분양가'는 모두 **'건물 분양가'**로 적고 토지임대료를 따로 적는다.
- 주변 시세 비교표에는 "땅값이 빠진 값이라 싸게 보인다"는 주의를 붙였다.

- 청약홈 첨부 공고문은 정정 전 파일이다. 평면도 링크는 SH 정정본 게시물로 건다.
