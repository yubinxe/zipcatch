# 발표 이미지 자산

`build-ir.js` 는 이 폴더에서 아래 접두사로 시작하는 파일을 찾아 자동 삽입합니다.
확장자는 `.jpg` `.jpeg` `.png` `.webp` 중 무엇이든 무방하며, 뒤에 어떤 글자가 붙어도 인식합니다.
(예: `hook-01-anyujin.jpg`)

| 접두사 | 내용 | 사용 슬라이드 |
|---|---|---|
| `hook-01` | 아이브 안유진 (초록 캐리어 광고 컷) | 1~3 오프닝 |
| `hook-02` | FOREON OLYMPIC PARK 로고 | 2~3 오프닝 |
| `hook-03` | 서울 아파트 전경 + 이재명 대통령 | 3 오프닝 / 10 정책 |
| `hook-04` | 안유진 디에이치 방배 청약 당첨 보도 | 8 제도 |
| `hook-05` | Richgo — 올림픽파크 포레온 최초 분양 당첨 난이도 | 9 시장 |
| `hook-06` | 국토부 장관 후보자 홍지선 — "집은 국가가 나눠준다" 보도 | 10 정책 |

파일이 없으면 해당 자리에 파일명이 적힌 자리틀이 대신 출력됩니다.
이미지를 넣은 뒤 다시 생성하십시오.

```bash
cd docs/presentation
node build-ir.js 집캐치_IR.pptx
```
