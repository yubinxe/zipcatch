# 역세권 가격 보정 가설 V0 — `transit-premium-heuristic-v0`

기록 2026-11-16 · 상태 **검증 전 가설**

이 문서는 현업 경험칙을 원문 그대로 보존하는 곳이다. 집캐치의 공식 가격 산정식이 아니다.
실거래로 보정한 모형이 나오면 **새 식별자**를 붙여 따로 적는다. 이 문서의 계수는 고치지 않는다.

## 3. 알려지지 않은 것 — 임의로 채우지 않는다

| 질문 | 현재 답 |
|---|---|
| 어느 시장(지역)에서 나온 계수인가 | 알 수 없음 |
| 거리는 직선거리인가 보행거리인가 | 알 수 없음 |
| 기준점은 역 중심·승강장·출입구 중 무엇인가 | 알 수 없음 |
| 매매가·전월세·땅값·사업성 중 무엇을 설명하나 | 알 수 없음 |
| 기준 가격에 지역 시장 수준이 이미 들어 있는가 | 알 수 없음 |
| 노선 수 효과가 거리 효과와 독립인가 | 알 수 없음 — 두 계수를 곱하는 것은 독립을 가정하는 셈이다 |
| 지상 역사 바로 옆의 소음 감가가 있는가 | 알 수 없음 |
| 노선이 늘면 실제로 닿는 일자리가 늘어나는가 | 알 수 없음 |
| 주택 유형·구·연식·시장 국면에 따라 달라지는가 | 알 수 없음 |
| 1,000m 밖, 100m 안은 어떻게 되나 | 원문에 없음 — 외삽하지 않는다 |

## 4. 쓰면 안 되는 방식

1. **중복 보정.** 역세권 단지의 실거래가에는 이미 역세권 프리미엄이 들어 있다. 그 가격에 계수를 다시 곱하면 같은 효과를 두 번 센다.
   비교 사례를 맞출 때는 두 물건의 차이만 반영한다: `보정 사례가 = 사례가 × (대상 계수 ÷ 사례 계수)`. 이것도 실험 시나리오일 뿐이다.
2. **공공임대·분양 공고가 바꾸기.** 공고문의 보증금·임대료·분양가·자격요건은 공식 값이다. 어떤 계수도 곱하지 않는다.
3. **위치가 불확실한 공고에 적용.** 공고명으로 찾은 좌표·시군구·시도 기준점은 '그 집의 거리'가 아니다. 주소 이상으로 확인된 자리만 거리 산정 대상이다.
4. **감정평가로 표시.** 집캐치는 감정평가법인등이 아니다. 「감정평가 및 감정평가사에 관한 법률」상 감정평가와 데이터 기반 시장 분석을 구분해 표기한다.
   허용 표기: 입지 접근성 분석 · 실거래 기반 비교분석 · 시장가격 참고 범위 · 실험적 보정 시나리오.

## 6. 검증 계획 (아직 하지 않음)

1. 역·출입구·운행 노선 공식 데이터 확보(서울교통빅데이터플랫폼 역사 마스터 등 — 지역마다 출처가 다르다).
2. 국토부 아파트 매매 실거래를 단지 단위로 정합화(이름만으로 같은 단지라고 보지 않는다, 해제 거래 제외).
3. 헤도닉 기준모형: 교통 변수 없는 모형 vs 있는 모형. 시간 기준 검증 구간, 가능하면 지역 기준 검증 구간.
4. 기록: 표본 수, 범위, 학습·검증 기간, 중앙 절대 백분율 오차, 거리 구간별 오차.
5. 판정: 원 계수가 대략 지지되는지 / 지역마다 크게 다른지 / 급지 효과와 겹치는지 / 근거 부족인지.
   원 계수를 맞히려고 모형을 조정하지 않는다.
