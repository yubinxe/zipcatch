## 요청할 자료와 쓰는 방식

1. **단지조감도(8쪽)** — 단지 소개 화면 배경 1장. 리사이즈·크롭·밝기 조정만. 합성·덧칠은 하지 않음.
2. **단지배치도(9쪽)** — 동 위치를 확인하는 평면도로 화면에 표시하고, 동 번호를 눌러 그 동의 층·호 표(공고 가격표)를 여는 데 사용. 벡터화 허락이 있으면 동 위치 좌표만 추출.
3. **동·호수 배치도(10~14쪽)** — 층·호 표의 '실제 위치·향' 표기. 지금은 호 번호 순서만 보여 주고 위치·향은 표시하지 않음.
4. **단위세대 평면도 정정본(15~39쪽)** — 주택형 화면에 그대로 표시(확대·축소). 방·가구를 다시 그리지 않음.
5. **단지 3D 모델 또는 매스 데이터(있으면)** — 지금의 매스 모형(지도 윤곽 × 층수)을 실제 형상으로 바꿈. 외관 재질은 허락 범위 안에서만.
