# 사업보고 PDF

`집캐치_사업보고.pdf` — 표지·목차 + 실제 서비스 화면 13개 (28쪽)

## 다시 만들기

배포된 사이트를 그대로 떠서 만든다. 화면이 바뀌면 다시 돌리면 된다.

```bash
# 1) 화면을 낱장 PDF 로 뜬다 (운영 화면은 접속 코드가 있어야 한다)
node scripts/capture-pdf.mjs --passcode=접속코드

# 로컬을 뜨려면
node scripts/capture-pdf.mjs --from=http://localhost:3000 --passcode=접속코드

# 2) 표지·간지를 붙여 한 권으로 묶는다
python scripts/build-report.py
```

## 왜 스크린샷이 아닌가

스크린샷을 이어 붙이면 글자가 이미지가 되어 흐려지고 검색도 안 된다.
브라우저 인쇄를 쓰면 **글자가 글자로 남는다** — 보고서를 받은 사람이 본문을
긁어 인용할 수 있고, 확대해도 깨지지 않는다.

## 찍을 때 조심한 것

- **다 그려졌는지를 시간으로 짐작하지 않는다.** 화면마다 "이게 보이면 다 그려진
  것"이라는 표식(`.cs-notice`, `a.cs-pin`, `.cs-heatcard` …)을 정해 두고 그것을
  기다린다. 빈 상자를 찍어 보고서에 넣는 것이 가장 나쁘다.
- **지연 로딩을 끌어내린다.** 지도 타일과 아래쪽 카드는 스크롤해야 뜨므로
  한 번 훑어 내린 뒤 찍는다.
- **화면에서만 뜨는 것은 감춘다.** 챗봇 단추·고정 티커·스크롤 진행선은 종이에서
  떠다니기만 한다. 등장 효과가 걸린 채 찍히면 반투명하게 남아 함께 끈다.
- **A4 로 자르지 않는다.** 화면 하나를 한 장으로 뽑는다. 잘라 넣으면 카드
  한가운데가 끊겨 보고서가 지저분해진다.

## 운영 화면

`/admin/*` 은 매 요청 서버에서 인증을 검사한다. 스크립트가 먼저 로그인해
세션을 받아 두고 들어간다. 접속 코드는 인자로만 받고 파일에도 로그에도 남기지
않는다. 코드 없이 돌리면 운영 화면이 로그인 화면으로 찍히고, 목차에 그 사실이
적힌다.

## 표지 숫자

표지의 수치(공고 169건 등)는 `scripts/build-report.py` 안에 적혀 있다.
자동으로 세지 않으므로 보고 전에 실제 값과 맞는지 확인한다.
