# 출시 차단 사항 점검 화면 (2026-11-02)

| 파일 | 무엇 | 출처 |
|---|---|---|
| `UNKNOWN-*`, `STALE-*`, `FIXTURE-*` | 첫 화면 표기·ONE MAP 패널 배지의 신선도 상태 | 로컬 빌드(`b532eb5` 이전 `9ffcace` 기능) + 운영 공개 읽기 API 응답. `STALE` 은 운영 공고 행 최신 변경 시각(2026-10-21 12:17 KST)으로 판정한 meta 를 응답에 넣은 것 — 운영 수집 실행 기록은 조회하지 않음 |
| `case-*` | 고덕강일 3단지 확인 사례 배지, 시계를 한국시간으로 고정 | 파일 이름 = 고정한 KST 시각 |
| `bridge-*` | HERO→ONE MAP 이어 붙이기 진행 0.05·0.3·0.6·0.97 | 헤드리스 Chromium(소프트웨어 렌더링) — 실기기 GPU 품질 근거 아님 |
| `director-qr.png` | 시연 마지막 장면 QR — 이 화면 캡처를 jsQR 로 실제로 읽음 | |
| `qr-destination-mobile.png` | QR 이 가리키는 주소를 쿠키·로그인 없는 휴대폰 브라우저(iPhone 13 에뮬레이션)로 연 화면 | 운영 사이트 |
| `preview-*` | Preview 배포(`f3466ac`) 실제 화면 — DB 없음(수집 시각 미확인), 가상 공고 쿠키, /map(카카오 401 로 지도 없음) | |
